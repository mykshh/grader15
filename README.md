# Grader

Сайт учёта оценок: вход по почте/паролю, подсчёт GPA по шкале АУЭС,
хранение данных в PostgreSQL (Neon), журнал заходов и админ-страница.

Один файл, одна зависимость (`pg`). Данные не теряются — лежат в базе.

## Что нужно: база данных Neon (бесплатно)

1. Зайти на **neon.tech**, зарегистрироваться (карта не нужна).
2. Создать проект (Create project) — база создастся автоматически.
3. Скопировать **Connection string** (строка вида
   `postgresql://user:pass@ep-xxx.neon.tech/dbname?sslmode=require`).

## Деплой на Render

1. Файлы (`server.js`, `package.json`, `README.md`) залить в репозиторий GitHub.
2. Render → New → **Web Service** → подключить репозиторий.
3. Настройки:
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: **Free**
4. В разделе **Environment Variables** добавить одну переменную:
   - Key: `DATABASE_URL`
   - Value: строка подключения из Neon (п.3 выше)
5. Deploy. Таблицы в базе создаются сами при первом запуске.

Порт Render задаёт сам (`PORT`) — настраивать не надо.

## Страницы

- `/login`, `/register` — вход и регистрация
- `/` — личный кабинет: добавление оценок и общий GPA
- `/admin` — список всех пользователей, их оценки и последние 50 заходов

## Запуск локально (по желанию)

Нужен Node.js 16+ и строка подключения к Postgres:

```
# Linux/Mac
DATABASE_URL="postgresql://..." node server.js

# Windows (PowerShell)
$env:DATABASE_URL="postgresql://..."; node server.js
```

Открыть http://localhost:3000

## Оценки

Вводишь предмет, процент (0–100) и кредиты — сайт считает букву (A, B+, …),
баллы GPA и общий взвешенный GPA.

## Примечание

Учебный пробник. Админ-страница `/admin` открыта без пароля — не держи там
ничего чувствительного и не используй настоящие пароли от других сервисов.
